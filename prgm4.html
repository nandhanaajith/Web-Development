CSS

CSS (Cascading Style Sheets) is a stylesheet language used to style and design web pages. It controls the appearance of HTML elements such as colors, fonts, sizes, spacing, backgrounds, and layouts. CSS helps make websites attractive, organized, and user-friendly. It can be added to HTML using inline, internal, or external CSS.
